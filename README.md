# Movie Recommendation System

## Project Description
This project recommends movies similar to the movie selected by the user using Machine Learning.

## Algorithm Used
- Content-Based Filtering
- Cosine Similarity

## Technologies
- Python
- Pandas
- Scikit-Learn
- Streamlit
- TMDB API

## Features
- Movie Recommendations
- Movie Posters
- Ratings
- Release Date
- Genres
- Overview

## How to Run
1. Install Python 3.10+
2. Install the required packages:
   pip install -r requirements.txt
3. Run:
   streamlit run app.py
